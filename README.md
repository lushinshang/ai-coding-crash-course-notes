# AI Coding Crash Course 課程導讀（非官方）

這是 [Matt Pocock 的 AI Coding Crash Course](https://www.aihero.dev/workshops/ai-coding-crash-course) 的非官方逐堂深度導讀，依照官方六大章節、59 個單元，逐堂讀完課程逐字稿後改寫而成，方便上課前先建立心智模型、上課時對照複習。

不含官方影片與逐字稿原文——那些是付費課程內容，請至 [官方課程頁](https://www.aihero.dev/workshops/ai-coding-crash-course) 購買觀看。

## 內容

- `index.html` — 課程總覽、五步驟系統、六章卡片
- `chapter-1.html` ~ `chapter-6.html` — 各章單元列表，每個單元可展開看深度導讀

## 開啟方式

直接用瀏覽器打開 `index.html`，或啟用 GitHub Pages 後透過網址瀏覽。
