第4章 基本功 · 4-06

動手做一個功能

不用任何技巧、直接讓 agent 做一個課程評論功能,當作整章後續技巧的對照基準。

探索也懂了,codebase 也熟了,這堂課終於要動手做東西——而且刻意選在還沒教任何規劃技巧之前先做一次。目的很明確:建立一個「什麼都不做特別處理」的基準線,好讓後面幾堂教的技巧有東西可以比較。要做的功能是課程評論系統:學生可以幫課程留星等評分,範例走的是登入、進到 Dashboard、看到修課清單,應該要能在頁面上打星星評分;第一版不做文字評論,只做星等,而且是所有人共用的全域評分,不用顯示是誰打的分數。

prompt 技巧建議很平實:如果是第一次用 coding agent,先想「使用者最後會看到什麼畫面」,再往回推需要做什麼——課程頁要看到全域星等、使用者要能選星數、教師能不能給自己課程打分數這種邊角案例先放著讓 agent 自己判斷。

這堂課真正要練的,是「觀察」而不是「操作」:一邊看 status line 上的 token 數字往上跳,一邊留意什麼動作特別耗 context;同時觀察 agent 面對這個任務時,探索階段是自己讀檔案還是生出 subagent。這些觀察會直接餵給下一堂——因為這次「素樸」跑法會暴露出一個問題:agent 探索完馬上就開始動手做,中間完全沒有跟你確認方向,而這正是下一堂要攤開來講的現象。
