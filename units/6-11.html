五步驟骨架:grill、spec、ticket、implement、review

收尾這堂課，Matt 把整章甚至整門課濃縮成一個五步驟骨架：grill（跟 AI 對齊想法）、spec（決定目的地）、ticket（拆解成一個個 smart zone 扛得動的份量，方便平行或依序執行）、implement（動手做）、review（做完再回頭檢查那些實作過程中無法檢查到的東西）。他強調這套骨架是他自己實際建構軟體的核心方法，就算工具本身一直在變——從 Ralph Loop 到現在比較常規的 loop，或者未來又冒出什麼新玩法——這個五步驟的形狀基本上都還撐得住。

他接著點出這門課只是打地基，真正要精進得往下面幾個方向深挖：怎麼把「implement」這一步從你得盯著螢幕看，變成可以丟給無人看管（AFK）的 loop 去跑；怎麼在動手寫 spec 之前，先用 prototype 或 research 去探路，把構想階段做得更扎實。他也提到了幾個延伸資源：AI Coding Dictionary（把 model、provider、token、context window 這些術語的心智模型打牢）、他的姊妹專案 Sculptor（一個在隔離沙盒裡做 AFK agent 的開源專案，也是他現在大部分實作工作背後真正在跑的東西）、以及持續在演進的 skill set 本身。

最後他把話說得很坦率：AI coding 這個領域還在快速變動，這套五步驟的形狀會被不斷細分、深化、長出新的枝節，但核心骨架他相信會留下來。他也把 Discord 社群定位成長期的支援管道——課程結束不代表關係結束，真的在實務上碰到搞不懂的狀況，回 Discord 找他和社群一起想辦法。
