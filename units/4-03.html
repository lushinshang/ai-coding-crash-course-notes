第4章 基本功 · 4-03

在 status line 顯示 context 用量

把 token 用量釘在畫面最下面,讓「context 偏執」變成隨時看得到的儀表板。
11.7K → 12K
一句摘要指令花掉的 token 用量

靠手動打 `/context` 才能看到用量,這個回饋迴路很「彆扭」——你得主動記得去查,而人永遠不會記得每次都查。真正管用的做法是把 context 使用量直接釘進 status line,變成眼角餘光隨時能瞄到的資訊,不用再刻意中斷工作流去問。

操作很輕量:到課程文章頁面複製一段 markdown 指令,貼進 agent,讓它照著步驟把 status line 設定寫進 `.claude/settings.json`。做完之後畫面下方就會固定顯示目前用了多少 token——一開始是 11.7K,讓 agent 幫忙做個摘要之後跳到 12K,也就是說那句摘要指令大概花掉 300 個 token。這個「一個動作值多少 token」的即時回饋,正是後面談成本效益判斷時真正的基礎——沒有這條線,所有關於什麼時候該清空、什麼時候還撐得住的判斷都只是憑感覺猜。

這堂課份量不大,但意義在於把「context 偏執」從一個要你刻意提醒自己的心法,變成環境本身就會替你盯著的習慣。後面每次提到「已經到了某個 token 數」「smart zone 快用完了」,指的都是直接讀這條線上的數字——沒設好這條 status line,後面判斷時機的節奏就會跟不上。
