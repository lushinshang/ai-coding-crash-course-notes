第3章 認識 Claude Code · 3-01

本章導覽

課程只借用 Claude Code 當教具，教的其實是所有 CLI harness 共通的操作直覺。

這門課會全程用 Claude Code 錄示範,但如果你把它當成一堂「Claude Code 操作課」,就理解錯了它的定位——它教的是「CLI 裡的 agent 該怎麼操作」這件事本身，Claude Code 只是剛好最多人在用、最方便拿來示範的那個載體。你可以換成任何其他能在終端機裡跑的 harness,底層的操作邏輯是同一套。

這個區分背後有個實際的理由。工具介面會變,選單會改版,快捷鍵可能下個版本就不一樣了,但「怎麼管理一段 session」「怎麼跟一個會自己執行指令的 agent 互動」「出錯了怎麼退回上一步」——這些是操作習慣層面的東西,學會了就能帶著走,換到別的工具也用得上。這也是為什麼這一章排在全課程最前面:它不是選修的暖身操,而是後面所有正式教學都預設你已經具備的底層肌肉記憶。

如果你完全沒用過任何 coding harness,接下來七堂會依序把 session 管理、prompt 輸入、IDE 整合、版本回溯、bash 執行、權限設定這些最容易卡關的地方一次講完。如果你已經是 Claude Code 老手也別急著跳過——裡面混了幾個進階技巧,不是純新手向的內容。
