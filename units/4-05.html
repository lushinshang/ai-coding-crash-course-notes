第4章 基本功 · 4-05

／teach skill

用 teach skill 把陌生 codebase 變成一堂為你量身打造的導覽課,而不是自己土法煉鋼亂逛。

換新工作、換新專案、在組織內部調來調去,每個人都經歷過「要搞懂一個陌生 codebase」的痛苦——通常的做法是自己一個檔案一個檔案點開,邊看邊猜。agent 在這件事上有明顯優勢,而 teach 這個 skill 就是把這個優勢放大到最大的工具。

安裝過程需要一點設定:先跳出目前的 agent session,在上層目錄用 `mkdir` 建一個新資料夾,在裡面跑 `npx skills add mattpocock/skills`,跳出的介面讓你勾選要裝哪個 skill(這裡只選 teach)、要裝在哪個 agent、要裝在專案層級還是全域(選當前目錄),安裝方式選 symlink。裝完之後在 `.claude/skills` 底下就能看到 teach。

實際用法是 `/teach`,接一句「教我這個 repo」,並且指向想了解的專案。這裡有個關鍵細節:prompt 裡要加一句「說明自己的經驗程度」——是資深工程師、剛入門的新手、還是完全沒碰過程式碼的門外漢,因為 teach skill 會根據這個自我定位調整講解深度。設定成一個中間程度的人設會得到不同的講解:做過一點 vibe coding、懂 TypeScript 基礎、沒碰過 React、對 client/server 和資料庫都還不太清楚,這種人設拿到的解說跟資深工程師拿到的,深度和用詞完全不一樣。

這堂課緊接在探索之後,等於是把「探索」從一次性的問答,升級成一套結構化、可重複使用、還會依照你的程度自動調整的學習流程。跟後面談 grill-execute-clear 循環的精神也是呼應的:teach 讓 agent 先充分理解環境再開口講解,grill 則是讓 agent 先充分理解需求再動手實作——兩者都是在對抗 agent「急著給出東西」的衝動。
