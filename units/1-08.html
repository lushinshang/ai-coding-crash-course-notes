安裝 request logger

把 agent 送去 Anthropic 的每一筆請求攔下來存成檔案，系統提示詞、工具清單全都看得到。
localhost:8787
本機 request logger 監聽位址

跟 agent 互動的體驗，本質上是一個黑盒子：文字打進去，答案跑出來，中間發生了什麼，完全看不見。這堂課要做的事，就是在這個黑盒子上撬開一條縫，而撬開的工具很簡單，是一個叫 request logger 的小程式，跑起來之後會在本機開一個網頁伺服器。

原理比想像中聰明，但操作起來只有一行設定：把一個環境變數指向這個本地伺服器，原本要直接送去 Anthropic 官方伺服器的每一筆請求，現在會先經過這個本地中繼站。中繼站做兩件事——正常轉送出去，讓 agent 照常運作，同時把整包內容留一份存到本機的資料夾裡。從使用者的角度看，什麼都沒變，打個招呼一樣得到「hello, what can I help you with」；但背地裡，每一次往返都被完整記錄下來了，黑盒子的內容第一次被攤在陽光下。

存下來的檔案裡，原始的 request 和 response 格式並不好讀，真正該看的是另外一份 markdown 版本——裡面完整攤開了送給模型的系統提示詞、工具定義，全部用 XML 標籤分隔開來，想看系統提示詞就直接跳到對應標籤，想知道工具清單有多長也是同一套邏輯，再往下就是完整的訊息歷史，一路對照到最後 assistant 回覆的那句「hello」。這不是要你現在就一頭栽進細節裡分析，後面的章節會花大量時間泡在這些 log 裡；這堂課的作用，是先把工具裝好、把原理搞懂。

真正的價值要到後面才會顯現：當你想知道「為什麼 agent 這樣做決定」，不用再靠猜，直接翻 log 就看得到系統到底跟模型說了什麼。這個工具目前只支援 Claude 和 Codex，但持續在擴充支援更多 agent——重點從來不是這個工具本身，是它打開的那扇窗，一旦你看過一次完整的 request 長什麼樣子，agent 的行為就再也不是玄學。
