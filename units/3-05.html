第3章 認識 Claude Code · 3-05

在時間軸上前進與回溯

rewind 模式加上本機持久化的 session,讓你敢放手讓 agent 大動作修改,因為隨時能整個倒帶。

想撤銷剛剛那次修改,最直覺的做法是打字告訴 Claude「revert that please」,它會照著上一步反著做一次,把刪掉的東西加回來。這個做法能用,但它本質上是「再叫一次 agent 做事」,還是得經過一次模型推論,而且只能撤回最後一步。真正的解法是連按兩下 Escape 進入的 rewind 模式——它不是叫 agent 幫你改回去,是直接把整條時間軸拉出來讓你選一個節點跳回去。

Rewind 模式會列出整條對話的每個互動節點,選中某個節點之後,系統給三種還原選項:只還原程式碼、只還原對話內容,或是兩者一起還原到那個時間點。最常用的是兩者都還原,直接把整個 session 拉回到指令下之前,像沒發生過一樣乾淨。想往回推更遠,同樣連按兩次 Escape 就能繼續選更早的節點,清單裡還有一個「summarize from here」選項,先留給後面章節講。這種「先試試看,不滿意就整個倒帶」的自由度,才是敢放手讓 agent 做大動作修改的真正底氣——沒有這層保障,很多人會不自覺地縮手,只敢讓 Claude 碰一兩個檔案,反而浪費了它處理大範圍修改的能力。

另一個容易被忽略但同樣重要的特性:Claude Code 的 session 是存在本機的,關掉終端機不代表對話就人間蒸發。連按兩次 Ctrl+C 離開後,有三條路接回去——系統印出的 `claude --resume <uuid>` 能精準回到那個 session;打開全新的 `claude` 再打 `/resume` 會叫出所有歷史 session 清單(甚至能在整個 repo 範圍搜尋);最快的是 `claude --continue`,直接接續上一個。知道 UUID 就用第一種最準,忘了細節就靠清單找,趕時間就用 `--continue`。倒帶跟復活這兩件事合起來,講的其實是同一件事:在這個時間軸上前進、後退,甚至跨 session 找回,都不用擔心一去不回頭。
