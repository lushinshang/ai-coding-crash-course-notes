第6章 把功能出貨 · 6-01

如何應付龐大任務

把龐大任務拆成一個個 session 扛得動的階段，並判斷何時該開新 session。

這堂課本地缺逐字稿，只能根據官網公開的課程簡介寫候補摘要。官網簡介是這樣寫的："Decomposing complex work into session-sized chunks — how to break down big projects into phases your agent can execute one at a time, and how (and when) to create a new session."

換句話說，這堂課要處理的問題是：一個大專案不可能塞進單一個 agent session 裡一次做完，你得先學會把它切成一階段一階段、每階段份量剛好落在一個 session 能負荷的範圍內。同時也會談到判斷時機的問題——什麼徵兆代表該收尾、開一個全新的 session 繼續下去，而不是硬撐著在同一個對話裡把 context 塞爆。

這是整章「從 issue 到出貨」流程的起手式，後面 6-02 到 6-05 講的 issue tracker、spec、ticket、implement，基本上都是在具體回答這堂課丟出的問題：怎麼拆、拆到哪個顆粒度、什麼時候換一個乾淨的 context 重新開始。
