重置回乾淨狀態

大部分學員的 agent 設定其實是過度配置，建議近乎粗暴：備份後全部砍掉重練。

幾乎每個帶著一身裝備走進這門課的人，都會被同一句話潑冷水：把它全部刪掉。裝過幾個 MCP 伺服器、調過一輪設定、裝過一票 skills 和 plugins——這些堆疊起來的結果，通常不是能力升級，是過度配置。理由很直白：那些配置大部分根本用不到，從一個乾淨的起點開始工作，反而更容易把事情做好。

但這不是要你不負責任地清空一切。如果那些設定是辛苦調出來的，捨不得就捨不得，解法不是自己動手刪，是讓 agent 自己處理——畢竟它應該最了解自己的設定放在哪裡。用一段固定的提示詞叫它去讀自己的文件、盤點所有設定檔案的位置，備份到安全的地方，再把環境清回空白狀態。這個做法之所以可行，是因為多數配置本來就是檔案形式的東西，備份跟還原理論上就是搬檔案這麼簡單，不需要什麼複雜的機制。

實際跑一次的流程是這樣：agent 先查自己的文件確認設定放在哪裡、盤點清單、備份到安全位置，完成後還會生成一段可以留著的還原提示詞，將來想找回設定時直接貼上去用。還原也同樣簡單——清空當下的對話狀態，貼上「用剛剛的備份還原我的設定」，整組設定就回來了，過程沒有任何一步需要手動搬檔案。

這麼做的真正用意，藏在一句玩笑話背後：這樣才能確保後面章節教的每個技巧，都不會跟你那堆（自己也承認）過度堆疊的舊配置互相干擾。後面每一個技巧為什麼有效、為什麼失效，都是在一個接近預設值的環境下驗證出來的，如果 agent 還背著一堆舊設定，某個技巧到底是課程內容的問題、還是被殘留配置搗亂，你會很難判斷。先歸零，才能乾淨地觀察每一步的因果。
