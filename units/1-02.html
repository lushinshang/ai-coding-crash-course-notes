選方案與選模型

免費方案撐不過第一次認真的 agentic session，訂閱制比 API 計費便宜二十到五十倍。
US$3,400
Theo 實付訂閱費
US$50,000
換到的 token 算力
20~50倍
訂閱制比按量計費划算

有個開發者這個月的 token 帳單，如果照牌價算，會逼近五萬美元。但他實際付出去的錢，只有三千四百美元——三千兩百美元的 Claude 訂閱，加兩百美元的 Codex 訂閱。同一份工作量，中間這個十幾倍的落差，不是誰算錯了，是訂閱制跟按量計費之間結構性的差距，划算程度可以到二十到五十倍，差距大小取決於你訂的檔次、以及你有沒有本事把額度用滿。

先把醜話說在前頭：免費方案完成不了這門課。這不是行銷話術，是能被驗證的事實——主要模型供應商的免費額度，設計出發點從來不是給這種吃 token 吃得很兇的 agentic 工作用的，你會在第一次認真跑一個 session 時就直接撞牆。這句話放在整門課第二堂就講，用意很明顯：與其讓你上到一半才發現額度燒光、體驗被硬生生打斷，不如現在就把期望值校正好。

具體該選哪一檔，答案其實不複雜。Anthropic 這邊，Pro 是起跳點，剛好夠應付課程需求；如果要專業使用，往上跳到 Max，Max 又分 5X 和 20X 兩檔——這門課錄製時用的是 20X，但坦白講，真正需要的頂多是 5X。OpenAI 那邊架構長得幾乎一樣，Plus 對應 Pro 的定位，額度不夠用了再往 Pro 升。這種近乎對稱的分層設計不是巧合，各家訂閱制邏輯本來就大同小異，一旦看懂一家，其他家不用重新學一次。

真正值得停下來想的，是訂閱制跟按量計費之間那個差距背後的心理機制。按量付費會製造一種很像家裡裝了電表的感覺——你會下意識地不想多用，這種心態一旦滲進工作方式，人會開始做出偏離理性的選擇：明明這個任務該上最強的模型，卻為了把數字壓低，硬是切成便宜模型將就，結果賠掉的是輸出品質，省下的只是幾塊錢。訂閱制把這個心理負擔整個拿掉，因為費用一開始就是固定的、上限是已知的，你才有餘裕把注意力放在「怎麼把這件事做好」而不是「這次又花了多少」。

所以最後的建議很直接：如果對用哪個 harness沒有特別偏好，Claude Code 配 Pro 是一個安全的起點；真的想走專業路線，就直接上 Max。而且不管哪一檔，都建議用訂閱方案內建的預設模型就好——如果你用的是入門檔次，卻硬要跑最頂級的模型，額度會被榨乾得特別快，這種組合注定撐不了多久。
